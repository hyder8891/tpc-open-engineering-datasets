## 1. 数据集定位与适用场景

本开源工程参考数据集专为**中资驻伊拉克电站、油气田（哈法亚、鲁迈拉、米桑、祖拜尔等）及水务基础设施项目部采购工程师**与跨国设备出口物流团队编写。[`iraq_hs_cosqc_matrix.csv`](./iraq_hs_cosqc_matrix.csv) 与 [`iraq_hs_cosqc_matrix.json`](./iraq_hs_cosqc_matrix.json) 系统梳理了 **HS 第 84 章（汽轮机/燃气轮机备件、离心泵、换热器、工业阀门、减速机、机械密封）、第 85 章（低压/中压电机、电力变压器、变频器 VFD、SITOP 电源、中低压开关柜、PLC/DCS 模块）及第 90 章（流量计、差压变送器、气体分析仪、API 670 振动监测）** 共 **33 个核心六位海关编码（HS6）** 的伊拉克进口合规要素。

## 2. 中国出口至伊拉克四大核心清关红线

1. **伊拉克 COSQC 装船前检验与符合性证书（Pre-Shipment CoC）：** 凡属伊拉克中央标准化与质量控制局（`COSQC`）管制目录内的机电产品，必须在**国内起运港发货前**向授权第三方检验机构（**SGS、TÜV 莱茵、Bureau Veritas 必维、Intertek 天祥**）申请文件审核（ISO/IEC 17025 检测报告）及仓库现场验货（PSI），取得正式 **CoC 证书**；货物抵达乌姆盖斯尔港或机场后凭原封铅封核验换取 **海关放行通知书（Release Note）**。严禁“先出运、后补证”。
2. **中国贸促会（CCPIT）原产地证与伊拉克驻华使馆认证：** 商业发票与原产地证（CoO）须经 **CCPIT** 认证并按合同/信用证要求办理**伊拉克驻华使馆领事加签**（注意：使馆认证原产地证不能替代 COSQC 技术符合性证书 CoC）。
3. **伊拉克 50Hz 电网制式与铭牌一致性：** 伊拉克全国工业电网标准为 **400V/230V 50Hz**（中高压为 **11kV / 33kV / 132kV / 400kV 50Hz**）。设备金属铭牌上的型号（MPN）、电压、频率、防爆等级（ATEX/IECEx）及序列号必须与商业发票、箱单及检测报告 100% 一致。
4. **海空联运入境口岸选择：** 大宗开关柜、电机及成套阀门优先发运至**乌姆盖斯尔港（Umm Qasr, `IQUMQ`，海运约 22–30 天）**或**祖拜尔港（Khor al-Zubair, `IQKAZ`）**；停机抢修急件（PLC 卡件、变送器、机械密封）优先直飞**巴士拉机场（`BSR`）**、**巴格达机场（`BGW`）**或**埃尔比勒机场（`EBL`）**（空运约 4–8 天）。
